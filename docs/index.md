# Welcome to the AUC SSE HPC Cluster

The High-Performance Computing (HPC) cluster at the **American University in Cairo (AUC) School of Science and Engineering (SSE)** provides state-of-the-art computational resources for research and education.

This documentation is divided into two primary sections:

* **[User Guide](user/getting_started.md):** Information on how to log in, compile code, load environment modules, and submit batch jobs using the Slurm Workload Manager.
* **[System Administration](admin/architecture.md):** Technical documentation regarding the deployment of KVM virtualization, NUMA alignment, Slurm database accounting, and storage networking.
